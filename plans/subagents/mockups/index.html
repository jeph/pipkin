The chosen design · a Subagents tab that opens a sheet

The Subagents tab on the message box never unfolds a panel. Tapping it opens the list of the chat's subagents in a sheet, and a row there opens that subagent in place of the chat, in the same pane, so it never touches your own split screen. Finished runs leave the list at your next message; the subagent tool row in the chat keeps the way back to them.
